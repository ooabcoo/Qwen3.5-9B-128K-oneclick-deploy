# 文档说明

本项目包含三个 Token Usage Proxy 相关文档：

## 文档列表

### 1. traffic-proxy-en.md (英文文档)
- **用途**：面向英文用户的技术文档
- **特点**：纯英文，技术术语保持英文
- **适用人群**：熟悉英文技术文档的用户

### 2. traffic-proxy-zh.md (中文文档)
- **用途**：面向中文用户的本地化文档
- **特点**：完全中文翻译，便于中文用户理解
- **适用人群**：中文用户，或偏好中文技术文档的用户

### 3. traffic-proxy.md (双语对照文档)
- **用途**：开发过程中的参考文档
- **特点**：每个章节都有中英文对照
- **适用人群**：开发团队内部参考

## 推荐使用

- **对外文档**：建议将 `traffic-proxy-en.md` 和 `traffic-proxy-zh.md` 作为对外文档
- **内部参考**：`traffic-proxy.md` 保留作为开发参考
- **README 链接**：在 README.md 中同时提供两个文档链接
